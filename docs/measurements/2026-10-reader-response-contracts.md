# Public reader response contracts, October 2026

The static tagged response schema improved valid delivery in this small public fixture, but both
schemas scored zero strict useful responses. This report changes no production code and does not
establish a memory benefit. The final fixed rationale contrast also scored zero strict useful
responses. Seven of ten attempts were unavailable, limiting causal interpretation. Independent
integrity and causal reviews confirm the negative result and the fixed stop.

## Static tagged schema contrast

Eight cells pair four transparent synthetic cases with the original schema and a static three-branch
schema. The source evidence, current request, policy, owned simulator state, and budgets remain the
same within pairs; only the response schema changes. The cases cover supported continuation, denied
permission, unknown progress, and conflicting report history with a scoped live simulator
observation. Three small English source graphs underpin the four cases. There are no independent
story-distribution or real-world reliability claims.

All eight original attempts stay in the denominator. Two original-schema responses passed the
supplied wire grammar but violated the local decision validator through nonempty action fields on
abstentions. Tagged schema requests were accepted by the actual native endpoint and all four tagged
deliveries validated locally; this does not prove universal grammar enforcement. All delivered
decisions abstained. Supported continuation and current observations did not reliably lead to useful
action; unsupported historical claims remained in refusal rationales.

## Measured cost and limits

The schema phase took 403.989629 seconds, excluding separately retained fresh source preparation. It
used eight physical generation requests and 76 physical HTTP requests, including 26 native
token-count operations (26 apply-template and 26 tokenize requests). All eight generations reported
usage: 10,672 input plus 1,242 output tokens, totaling 11,914. Fresh source preparation used nine
local workers, seven stores, ten local embedding items, and no provider calls. Local driver CPU was
0.673355 user and 0.341784 system seconds; child CPU was 4.236321 user and 2.126938 system seconds.
Peak driver and child RSS were 59,277,312 and 64,241,664 bytes. Component times overlap and do not
sum to model compute.

Both arms used the already loaded LAN reader ornith15 and the same native template, temperature
zero, seed 42, and thinking disabled. Whole input was capped at 7,040 tokens, output at 1,024, with
128 reserve inside 8,192. Equal ceilings do not imply equal realized compute. Server CPU/GPU,
energy, hardware cost, money, and platform author/reviewer/grader calls, tokens, and money remain
unknown. No model install, paid API, private memory transfer, or security change occurred.

## Final rationale instruction contrast

Ten fixed cells pair five cases on three fresh transparent English synthetic graphs. Both arms use
the same static tagged schema, user packet, source evidence, initial owned state, and caps; only one
appended system instruction bundle differs. The bundle asks for short evidence-specific rationale
and distinguishes unknown progress, inactive history, current observations, and present permission.
It tests those changes together, not brevity alone. The fifth case is a supported reported fact
whose answer needs no simulator permission. Instruction compliance is descriptive and does not alter
the semantic scoring gate.

This single pass does not establish an instruction effect: small shared graphs, fixed execution
order, and seven unavailable attempts limit comparison. It changes no production behavior. The fixed
stop rule is now reached; there are no additional public prompt/schema/model variants, retries, or
heldout opening. Deployment remains blocked by supported response quality and delivery within the
declared budget.

## Broader diagnostic cost lower bound

Across budget-v2 development, reader-comprehension-v1, continuation-public-v2, response-contract-v1,
and this rationale contrast, the recorded total is 991 physical HTTP requests and 77 physical
generation attempts. Reported usage totals at least 126,193 tokens; eleven attempts have unknown
usage. This deliberately scoped lower bound excludes earlier campaigns, source preparation, native
platform caller activity, and platform author/reviewer/grader activity. Server compute, energy and
monetary cost remain unknown. It is neither a deployment cost estimate nor an equal-cost quality
comparison.
