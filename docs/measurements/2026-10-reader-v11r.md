# V11r segment-locator reconstruction: closed quality failure

The freshly authored paired continuation panel failed the fixed gate. Recovered-design source blocks
produced 7/16 strict useful answers; the segment-locator candidate produced 5/16, with 3 and 2
critical-error candidates respectively. The candidate was below 14/16 and worse than its baseline.
Every one of the 32 answers was delivered, validated and persisted; delivery integrity did not
establish useful, grounded continuation. No production reader integration or merge is justified.

The machine-readable aggregate, audit totals and arm costs are retained in
[2026-10-reader-v11r-summary.json](2026-10-reader-v11r-summary.json).

## Recovery boundary and fixed intervention

This is a reconstruction on the always-on Mac, not a migrated Windows V11 patch. The original local
Windows checkpoint, runtime, fixtures and gold were unavailable. Authorized prior-thread tool outputs
recovered the exact V5 concise system literal, V9 format policy, V9 block schema/renderer excerpt,
and the V11 lexical/cap/accounting design. The original candidate policy literal and selector field
name were unavailable. Their replacements and the new runtime/runner/auditor/proofs are versioned
V11r. No original 120-proof result is claimed; this reconstruction passed 60 new offline tests,
including independent repetition. Two independent reviewers permitted freezing and public execution.

The baseline emits ordered text blocks with original source event IDs. The candidate instead selects
copy-free lexical source-segment locators; its lossless segmented packet changes only source body
representation. Host code reconstructs canonical source bodies, maps selected locators to stable
original IDs, and renders those IDs beside unchanged block text. It performs no semantic correction,
normalization, quotation repair or hidden model call. Valid locator selection proves provenance
membership, not entailment, current status or permission.

Both arms use equal complete authorized source history and query, the recovered concise system,
one model call, temperature 0, seed 42 and disabled thinking. Candidate-only policy/schema/packet
changes are the necessary intervention. Both use one full-basis gate revalidation and atomic turn
write. Limits remain 4096 total tokens, 3008 input, 1024 output, 64 safety reserve, 49152 wire bytes,
16384 final UTF-8 bytes, 16 sources, 32 lexical segments/note, 128 total segments, 12 blocks and
16 selectors/block. Nothing is pruned, merged or truncated to fit. No retries, semantic tuning after
execution, changed backend or easier replacement cases occurred.

The fixed backend was the authorized LAN endpoint with model ID `ornith15`. The other authorized
server was not used for this experiment. Only new synthetic scenarios and queries reached the model;
local gold never entered the runner or its requests. No real memory migration, paid API, model
installation, service/security change or user-application termination occurred.

## Admission, blinding and closed result

The newly authored public protocol gate passed 4/4. A separate audit bound actual HTTP requests and
responses to policies, schemas, queries, canonical source packets, parsed output, final renderer,
committed events and session history. The audit independently replayed fixtures through MemoryGate,
opened original SQLite read-only, and verified both committed events and both history rows. It derives
an exact fixture-based denominator: empty or shortened reports cannot produce a vacuous pass.

Only after public PASS did a fresh independent author receive the prospective contract without prior
panels, outputs, methods, prompts or scores. The frozen panel has 8 stories, 2 checkpoints each,
40 events, 6 personal/2 project stories, 4 EN/4 RU stories, 2 explicit correction chains and 2
unrelated-scope forget operations. Whole-note correction semantics and source-grounded grading
criteria were specified before outputs. A distinct fresh grader received only opaque candidate IDs,
queries, canonical authorized sources, delivered artifacts and frozen gold. Methods, schemas, prompts,
cost and mapping were withheld. Style can partly reveal a method, so complete blinding is not claimed.

All 32 planned slots remain in the denominator. Mapping, masked packet, audit and reports were bound
by retained hashes before grading. All judgments were frozen before unmasking, with no rescoring.
