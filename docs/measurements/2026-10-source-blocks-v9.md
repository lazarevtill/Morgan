## Bounded intervention and integrity

V8's status-policy append did not improve its paired result. Its postgrade audit identified
mechanical omitted, abbreviated or misplaced citations as well as unsupported citations and critical
assertions. V9 tested one structural intervention: one chat returns ordered final text blocks plus
selected exact source IDs; a deterministic renderer places those IDs beside each block. Baseline
retained unchanged V5 concise system and TextResult. Candidate used the same concise base plus only
the block-format directive, dynamic strict schema and renderer. V8's status-policy append was
discarded; no extra extractor/checker/model call, pruning, rewriting, source promotion, semantic
repair or retry.

Both receive byte-identical complete authorized-history packets and query, with exact original event
bodies, actors, timestamps, source labels, active/inactive states and revision lineage. Whole
immutable notes do not inherit unstated current clauses. Existing scope, erasure generation,
full-basis current-time revalidation, fresh-session and atomic commit checks remain. Per-slot
lifecycle replay prevents final contamination; unrelated-scope forgetting clears its manifest, while
synthetic evaluation snapshots remain retained.

Candidate schema: 1–12 ordered blocks, nonblank text, 0–16 unique source IDs constrained to actual
delivered IDs. Empty selections permit purely creative wording/headings/marked proposals; they do
not exempt unsupported source-dependent claims from grading. Text/order are preserved, with adjacent
selected IDs added mechanically. Both final artifacts enforce 16,384 UTF-8 bytes before persistence.
Invalid shape/selected IDs/duplicates or oversized rendering make the slot unavailable, without
repair or semantic retry. Valid IDs and adjacency do not establish entailment, present authority or
truth.

Identical model/options/budgets: temperature 0, seed 42, thinking false; 3,008 input + 1,024 output
+ 64 reserve within 4,096; 49,152 full HTTP generation bytes; three transport attempts with bounded
2/8-second backoff, no actual retries. Schema/directive overhead and failures count. Dynamic format
keys create extra metadata reads; none are hidden or optimized away. Local hash embeddings,
synthetic LAN only, no embedding endpoint requests. CPU/energy/server/grammar effects are unmeasured
causal limits.

Global arm order was assigned before endpoint calls: eight baseline-first/eight source-block-first
pairs. Exact story::checkpoint identities and fixed 32 denominator survive failures. Anonymous
preadmission bookkeeping retains paired planned slots without inventing a query, source or authored
gold; it was not needed in this admitted run. Fresh independent author follows the already frozen

actual query/source packets and frozen gold, without arms/methods/prompts/schema/cost/mapping.
Partial masking through output style/source remains. Strict list/boolean/identity/availability shape

Fresh panel: 8 stories, 16 checkpoints, 6 personal/2 project, 4 EN/4 RU, 40 events, 11 revision
