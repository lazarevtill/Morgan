# Public reader and continuation contracts: no quality admission

Two separately frozen public diagnostics did not establish an overall memory-quality benefit.
A neutral envelope legend did not improve the first diagnostic. A second stateful diagnostic
made matching-state continuations useful, but introduced no demonstrated advantage from explicit
state adoption or live observation and retained unsupported rationale claims. These results
leave the failed budget-v2 development result and its unused 16-story holdout unchanged.

## Public reader comprehension v1

One transparent fixture graph supplied four tasks, three envelope forms and two parent-presence
conditions: 24 fixed single-shot cells. Bodies were identical within a parent condition.
Source-only removed sections/version/bounds together; empty sections retained the inspect
frame; a neutral legend explained selection, reported state and current action authority.
The source-only intervention was a bundle, not an isolated sections change.

All six authorized continuation cells failed. Five valid decisions abstained; one abstention
populated action fields and failed local validation. Responses recognized the reported next
stage but questioned whether historical evidence established executable current state.
A legend did not solve that public problem. The original executor checked permission and
allowlists but had no persisted completion prefix or next-step validation; that limits what
its effects demonstrated without invalidating its frozen grades.

Grading history is part of the result. The first independent grader imposed an array-only
citation requirement absent from the frozen contract and returned 0/24 strict passes with two
critical findings. That artifact remains unchanged. Before root unblinding, a contract-only
reviewer who saw no outputs ruled that clear inline supplied source IDs linked to supported
claims qualified. A fresh grader applied the original rules to the unchanged outputs and
returned 13/24 with one critical and four unknown findings. Three critical classifications also
differed through materiality judgments; the correction was not solely a citation-container
change. An independent integrity review verified this sequence. No rubric, reference, response
or model call was changed or repeated, and the improved count is not a quality promotion.

Cost: 224 physical HTTP requests, 84 native counts and 24 generations. Twenty usage receipts,
including the invalid-schema response, reported 23,598 input plus 2,848 output tokens. Four
cancelled generations have unknown usage, not zero. Export wall was 1,874.81 seconds. Five
failed deliveries—four generation timeouts and one validation error—remain in the denominator.
Preparation reused a separately reviewed transparent offline graph: five actual Gate processes,
six stores and seven local embedding items, with zero source-provider calls.

The first independent grade was saved before mapping: 7/12 useful, five critical findings.

The first critical count remains unchanged. Independent review flagged one taxonomy boundary:
the malformed live-conflict row clearly fails usefulness and contains contradictory action

examples. No replacement grade or favorable revised aggregate was substituted. Future scoring
must distinguish unsupported state assertions, wrong attempted action fields, schema-only
inconsistency and safe uncertainty prospectively.

## What follows from these observations

Live observation adds information, explicit adoption changes request semantics, and all second
conditions share a changed common policy and stateful executor. These small public tests do
not isolate memory rendering, explain the earlier failure causally, or estimate long-lived
reliability. Task semantics and observations can reveal conditions despite opaque IDs.
The same already-loaded reader and ceilings were used; equal ceilings are not equal realized
input, compute, time or money. Server CPU/GPU/energy/hardware/money and platform
research/author/reviewer/grader calls/tokens/money remain unknown for both diagnostics.

A separate offline tagged-schema prototype passed 17 tests and independent format review.
It encodes local empty/nonempty action-field invariants, and optionally current caller
project/permission/correlated task-step allowlists, without encoding the correct next stage.
It cannot make a rationale factual. Native server compatibility remains unverified. Any later
public contrast must use fresh frozen cases and keep schema and rationale interventions
separate. No production behavior or model policy was changed by this report; no real memories,
closed gold, original caller text or per-case responses are published.
