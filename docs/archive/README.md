# Archive

Documents that shaped Morgan but no longer describe it: the platform-era designs the
[local-first reshape](../design/local-first-reshape.md) narrowed (multi-agent hosting, device
sync, a voice layer, an MCP host, deployment profiles), the research snapshots behind the
[decision records](../decisions/), and the benchmark report of the pre-reshape text path.
They are kept for the reasoning they contain, not as a description of the current system;
the code they describe is in the git tags `legacy-v0.0.4-full` and `legacy-v0.0.3-monolith`.
