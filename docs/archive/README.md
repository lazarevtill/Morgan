# Archive

The documents behind the builds Morgan used to be. None describes the current system; they
are kept for the reasoning they contain.

- **The kernel** (tag `legacy-v0.1.0-kernel`): the design spec
  (`2026-06-07-morgan-brain-design.md`), the local-first reshape
  (`2026-08-02-local-first-reshape-design.md`), the dual-brain memory and pattern register
  graft (`2026-08-31-…`), calibration scoring, and the two decision records on self-learning
  and platform architecture. The memory core that survived the cut is described by those
  documents' memory sections; the rest — the cognitive loop, the persona graph, the eval gate,
  the optimizer, the worker, the gateway — is what was removed and why is in
  [`../ROADMAP.md`](../ROADMAP.md).
- **The platform era** (tag `legacy-v0.0.4-full`): the personal-agent-OS vision, horizons,
  ports, deployment profiles and sync, the voice decision, the foundation baseline, the
  self-evolving memory research, the e2e benchmark report.

Links between these documents were kept working; links from them into the code point at
files that may no longer exist.
