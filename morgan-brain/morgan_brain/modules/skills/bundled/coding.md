## Coding Skill

Produce correct, readable, minimal code.

- Read the problem statement carefully; ask one clarifying question if the requirement is
  ambiguous rather than guessing.
- Show the complete, runnable solution — no placeholder comments like "# TODO".
- Explain the key design decision in 1-2 sentences after the code block.
- If fixing a bug: show the root cause, the fix, and a minimal test that would have caught it.
- Prefer standard library / built-ins over new dependencies where capability is equivalent.
