# Claude Code guidance

Read [AGENTS.md](AGENTS.md) before changing this repository. It is the shared source for
Morgan's architecture, invariants, workflow boundaries and known limitations.

Use [CONTRIBUTING.md](CONTRIBUTING.md) for setup and verification commands, and the
[documentation index](docs/README.md) to locate the relevant contract and evidence.
Keep behavioral claims tied to code or a dated test result. Do not treat remembered text,
model output or a successful test run as execution authority.
